Autonomous Pathfinding & Ground Station Simulator

Project NETHRA (Navigational Eye for Terrain Hazard Reconnaissance & Avoidance) is an autonomous UGV ground control system engineered to simulate disaster reconnaissance across hazardous, GPS-denied environments using dynamic A* path replanning.

🗺️

Dynamic A* Navigation

Real-time path planning across a 12x12 discrete costmap. Instantly calculates the lowest-cost detour when barriers are placed.

🕹️

Full Operator Control

Supervisory telemetry station with Start, Pause, Resume, and interactive hazard tile placement directly from the ground cockpit.

🛡️

Boundary Failsafes

Prevents illegal movements through obstacle coordinates and automatically triggers safe emergency stops if all pathways are blocked.

📐 Mathematical Foundations: The A* Algorithm

Path computation evaluates potential grid moves using the standard evaluation formula:

f(n) = g(n) + h(n)

• g(n): The exact movement cost from start node (0, 0) to current node $n$.
• h(n): The admissible Manhattan distance $\vert{}x_1 - x_2\vert{} + \vert{}y_1 - y_2\vert{}$ to target (11, 11).

Because the vehicle moves in 4 cardinal directions (North, South, East, West), the Manhattan heuristic is mathematically admissible (it never overestimates the true remaining distance), guaranteeing the optimal shortest path without evaluating unnecessary unpromising nodes.

Algorithm Evaluation Strategy Suitability for Real-Time Detouring
Dijkstra's Algorithm Expands outwards equally in all directions without target orientation. High computational overhead on larger grids due to exhaustive search.
Breadth-First Search (BFS) Uninformed uniform expansion across neighbor levels. Inefficient for directed target navigation.
A* (A-Star) Planner Directed heuristic search prioritising target corridor. Optimal for rapid detours with sub-millisecond execution times.
